### 3. server/controllers/loginController.js

**Confidence:** HIGH  
**Breaking Changes:** No

**Explanation:** Validated input presence. Added bcrypt compare for password. Signed JWTs with separate secrets and expiries. Saved refresh token in DB for rotation. Set cookie flags to prevent XSS and CSRF.

**Security Notes:** Rotate and blacklist compromised tokens. Use HTTPS to protect cookies.

**Additional Dependencies:**

**Testing Recommendations:**

### 4. server/controllers/logoutController.js
**Vulnerability:** SESSION_MANAGEMENT_FLAW  
**Confidence:** HIGH  
**Breaking Changes:** No

**Explanation:** We lookup the user by refreshToken and clear it server-side. Then we clear the cookie with identical flags to prevent stale tokens.

**Security Notes:** Ensure cookie name matches exactly. Consider logging logout events.

**Additional Dependencies:**
None

**Testing Recommendations:**
- Logout while logged in
- Logout with no cookie

### 5. server/controllers/refreshTokenController.js
**Vulnerability:** AUTHENTICATION_BYPASS  
**Confidence:** HIGH  
**Breaking Changes:** No

**Explanation:** Verified that refresh token matches the stored one. Verified signature and username. Rotated the token by issuing a new one and saving it. Sent cookie with secure flags.

**Security Notes:** Rotation prevents replay. Monitor token reuse attempts.

**Testing Recommendations:**

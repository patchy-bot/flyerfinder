### 1. server/controllers/flyerController.js
**Vulnerability:** AUTHORIZATION_FAILURE  
**Confidence:** HIGH  
**Breaking Changes:** No

**Explanation:** 1. We check req.user.role to enforce only 'admin' can create flyers.  
2. We verify presence of required fields to prevent empty payloads.  
3. We attach createdBy from JWT to track creator.

**Security Notes:** • Ensure verifyJWT middleware runs before this controller.  
• Log unauthorized attempts for auditing.

**Additional Dependencies:**
None

**Testing Recommendations:**

- Admin user request creates flyer
- Missing fields returns 400
